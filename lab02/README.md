# Лабораторная работа №2: Сравнение производительности коллекций в C#

## Цель работы

Сравнить производительность операций над различными типами коллекций: List, LinkedList, Queue, Stack и ImmutableList.

## Требования

- Сравнить производительность операций добавления, удаления, поиска и получения по индексу
- Работать с коллекциями размером не менее 100 000 элементов
- Написать автоматизированные тесты, проверяющие корректность всех операций
- Использовать Stopwatch для измерения времени выполнения
- Выполнять каждую операцию 5 раз и усреднять результаты
- Сделать выводы о преимуществах и недостатках каждой коллекции

## Используемые технологии

- .NET 8.0
- C# 12
- xUnit для тестирования
- System.Collections.Immutable для неизменяемых коллекций

## Инструкция по запуску

1. Установите .NET 8.0 SDK
2. Склонируйте проект и перейдите в его директорию
3. Запустите бенчмарки производительности:
   ```
   dotnet run
   ```
4. Запустите автоматизированные тесты:
   ```
   dotnet test
   ```

Программа предложит выбрать режим работы: полное тестирование всех операций или только тестирование вставки. Результаты будут выведены в консоль в виде среднего времени выполнения операций в тактах.

## Выводы

### List

- Быстрый доступ по индексу и добавление в конец
- Медленная вставка/удаление в начале и середине из-за сдвига элементов
- Лучший выбор для частого доступа по индексу

### LinkedList

- Быстрая вставка/удаление в любом месте при известном узле
- Медленный поиск (линейный обход)
- Лучший выбор для частых изменений структуры списка

### Queue

- Оптимизирована для FIFO операций
- Только добавление в конец и удаление из начала
- Использовать строго по назначению

### Stack

- Оптимизирована для LIFO операций
- Только добавление и удаление с вершины
- Использовать строго по назначению

### ImmutableList

- Потокобезопасна, неизменяема
- Самая медленная при модификациях
- Использовать при необходимости неизменяемости
