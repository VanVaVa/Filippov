# Лабораторная работа: Сериализация JSON, управление ресурсами и работа с файлами в C#

## Описание задачи

Данная лабораторная работа направлена на освоение ключевых аспектов работы с файлами, сериализацией JSON и управлением ресурсами в C#. В рамках работы реализованы три основных компонента:

1. Класс `Person` с поддержкой JSON-сериализации и валидацией данных
2. Класс `PersonSerializer` для работы с JSON-сериализацией и файловыми операциями
3. Класс `FileResourceManager` для управления файловыми ресурсами с реализацией паттерна `IDisposable`

## Цели работы

1. **Освоить использование атрибутов JSON** для управления процессом сериализации/десериализации
2. **Изучить паттерн IDisposable** для корректного освобождения ресурсов
3. **Научиться работать с файловой системой** (чтение/запись файлов)
4. **Реализовать сохранение и загрузку объектов** в/из файлов JSON
5. **Понимать разницу** между явным освобождением ресурсов через `Dispose()` и автоматическим через финализатор

## Технологии и библиотеки

- **.NET 8.0** - целевая платформа
- **System.Text.Json** - для сериализации и десериализации JSON
- **xUnit** - для модульного тестирования
- **C# 12** - современные возможности языка

## Установка и запуск

### Требования

- Установленный [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) или выше
- Любая IDE (Visual Studio 2022, VS Code, Rider) или командная строка

### Шаги для запуска

1. **Клонирование/скачивание проекта**

2. **Восстановление зависимостей**

   ```bash
   cd lab01
   dotnet restore
   ```

3. **Сборка проекта**

   ```bash
   dotnet build
   ```

4. **Запуск приложения в проекте lab01**

   ```bash
   dotnet run
   ```

5. **Запуск тестов в проекте lab01tests**
   ```bash
   dotnet test
   ```

### Покрытие тестами

- **PersonTests**: Тестирование валидации, JSON-атрибутов и вычисляемых свойств
- **PersonSerializerTests**: Тестирование сериализации и файловых операций
- **FileResourceManagerTests**: Тестирование управления ресурсами и IDisposable

## Особенности реализации

1. **Обработка исключений**: Все файловые операции защищены try-catch с логированием ошибок
2. **Кодировка**: Используется UTF-8 для поддержки Unicode символов
3. **Потокобезопасность**: Реализована через блокировки для конкурентного доступа
4. **Асинхронность**: Поддержка async/await для неблокирующих операций
5. **Корректное освобождение ресурсов**: Реализация паттерна Dispose
