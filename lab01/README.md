# Лабораторная работа 1

Задачей лабораторной работы было создание класса Person и класса PersonSerializer для превращения объекта класса в JSON и обратно, а также менеджера для работы с файлами

## Используемые библиотеки

Из внешних библиотек был использован только модуль для тестирования Xunit
Также были использованы внутренние средства для работы с JSON и файлами

## Запуск

Для запуска необходимо сделать dotnet restore в директории lab01 и lab01tests

Для запуска простых примеров работы можно использовать dotnet run в проекте lab01
Для запуска тестов можно использовать dotnet test в lab01tests
